# 性能基准

[← 返回 README](../README.md)

本页保留 2026-10-05 的 Windows 基准样本，供复现和对照。后续版本的性能需重新测量。

p50 表示中位延迟，p95 表示从小到大排列后覆盖 95% 样本的延迟，吞吐表示每秒完成的请求数。

## 测试方法与复现

`benchmark4csql` 启动真实服务端，经 TCP 测量 SQL 到持久存储的完整链路，结果校验通过后输出 `BENCHMARK_OK`。

### 构建与运行

先在 `chusql-core/storage/` 执行 `cargo build --release`，生成优化后的存储动态库。再进入 `benchmark/`，在 PowerShell 中构建并运行：

```powershell
$repoRoot = (Resolve-Path '..').Path
$benchmarkTemp = Join-Path $repoRoot 'logs/benchmark-tmp'
New-Item -ItemType Directory -Force -Path $benchmarkTemp | Out-Null
$env:TEMP = $benchmarkTemp
$env:TMP = $benchmarkTemp
$env:PATH = (Join-Path $repoRoot 'chusql-core/storage/target/release') + ';' + $env:PATH
$env:GHC_CHARENC = 'UTF-8'
stack build chusql-core-model chusql-core-engine chusql-interface chusql-server chusql-bootstrap benchmark4csql --force-dirty --ghc-options=-O2
stack exec -- benchmark4csql 10000 50000
```

Linux 下用 `LD_LIBRARY_PATH` 指向 release 存储目录。两个参数分别是用户数和订单数，默认 10,000 / 50,000，每个至少 100。

### 采样与结果校验

读取预热一次、采样七次，p95 等于最大值。并发点查使用 1、4、8 个客户端，各 100 次请求；吞吐按整体耗时计算。写入保留正常持久化路径，各场景测量一次。

## 实测环境

- 测量日期：2026-10-05，Asia/Shanghai。
- CPU：AMD Ryzen 7 7840H，8 核 / 16 逻辑处理器。
- 可见物理内存：31.2 GiB。
- 系统：Windows 11 专业版，10.0.26200。
- 数据目录：D 盘 NTFS 上仓库 `logs/` 的临时子目录；未测存储设备裸吞吐。
- 编译：GHC 9.10.3，Haskell 本地包 `-O2`，Rust release 动态库。
- 规模：10,000 用户、50,000 订单、5,000 条 512 字节字符串宽行；订单按用户循环分配，年龄按 100 个值循环分布。

## 性能测试结果

启动、引导、认证及创建基准库合计 0.62 秒。纯 TCP Ping 200 次平均 0.100 ms，schema catalog 200 次平均 0.267 ms。主键点查另外连续执行 100 次，平均 0.300 ms，100/100 命中。

## 事务基准

同日、同一台机器、10,000 用户 / 50,000 订单规模的独立测量，结果校验通过。日志为本机 `logs/repair-txn-performance.log`，与上面的场景不是同一次采样。

| 指标                    | 耗时（ms） |
| ----------------------- | ---------: |
| 200 次独立持久化 INSERT |    1,134.7 |
| 事务 200 条 INSERT 总计 |    687.355 |
| BEGIN                   |    269.806 |
| 事务内 200 条 INSERT    |     41.129 |
| COMMIT                  |    376.345 |

事务写入约 290.97 行/秒，BEGIN 与 COMMIT 合计约占总耗时的 94%。

## 瓶颈与使用范围

样本中，事务启动与提交、相关子查询和大结果扫描的成本较高。具体瓶颈需在当前版本重新测量和分析。

这是单机回环、热缓存为主的样本。生产容量、冷缓存、远程网络和混合读写需单独验证；跨版本比较应保持环境与数据分布一致，并多次独立运行。

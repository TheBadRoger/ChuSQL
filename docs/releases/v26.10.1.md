ChuSQL 首个正式发布版，提供 SQL 查询与写入、连接、聚合、子查询、索引、事务、保存点、崩溃恢复和用户角色授权。Haskell 引擎与 Rust 存储层提供服务，CLI 用于访问。

本版支持 String、List、Maybe、Tuple 等运行时类型，以及 length、not 函数。

## 安装

提供 Windows x86_64 和 Linux x86_64 发行包，内含服务端、CLI 及安装脚本，附 SHA256 校验。[安装指南](https://github.com/TheBadRoger/ChuSQL/blob/v26.10.1/docs/install.md) · [SQL 语法](https://github.com/TheBadRoger/ChuSQL/blob/v26.10.1/docs/syntax.md)。

## 使用提醒

适合学习、开发和小规模试点。事务使用整库内存快照，同库写入串行；DECIMAL 使用浮点，复合类型的比较和索引能力有限。上线前测试负载并演练备份恢复，升级前备份数据。

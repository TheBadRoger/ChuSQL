本版降低 TCP 请求与权限读取的延迟，并包含 v26.10.2 之后已提交的安装和客户端改进。

## 主要变化

- TCP 连接关闭小包等待，JSON 响应与换行共同发送，消除小响应约 40 ms 的固定等待。本地 Unix socket 保持原有行为。
- 权限检查只创建当前目录中缺失的系统表，复用同次目录读取中的稳定对象身份，减少重复存储调用。每次请求仍重新检查身份和权限，保留撤权、删除重建和旧后端行为。
- Linux 可通过可选 Unix socket 验证本机 root 身份，使用 CLI 免口令登录。
- 客户端驱动独立维护，服务端统一提供会话、认证和配置模块；发行流程提供 Debian 包和 ChuRepo 软件包渠道。

## 性能与验证

单 CPU、512 MiB 的 Linux 容器，八张小表，同一数据目录，每组预热两次并采样十二次。普通账号简单查询的中位往返时间从约 60 ms 降至 8.6 ms，BEGIN／SELECT／COMMIT 从约 148 ms 降至 9.8 ms；PING 从约 44 ms 降至毫秒以下。实际收益取决于网络、数据规模和负载。

本地全量门禁通过：Rust 226、Engine 631、Server 175、CLI 19、Bootstrap 10，零失败。Server 有三个需要 root 的本机身份测试在普通用户下 pending。真实存储回归覆盖权限表补建、目录错误、稳定身份复用及无身份元数据的后端回退；HLint 无提示。

## 安装与升级

提供 Linux x86_64 和 Windows x86_64 发行包及 SHA256 校验，Linux 另有 Debian 包。[安装指南](https://github.com/TheBadRoger/ChuSQL/blob/v26.10.3/docs/install.md)。

本版性能修改不改变 TCP 消息格式或持久化格式。升级前停止服务并备份完整数据目录。若从 v26.10.1 或更早版本升级，还须遵循 v26.10.2 的行版本格式升级约束；回退使用旧程序和升级前备份。

# ChuSQL v26.10.2

ChuSQL 是一个以 SQL 为主要接口的关系数据库，由 Haskell 查询引擎和 Rust 存储层组成。服务端管理数据与用户会话，用户可通过命令行客户端或浏览器中的 Web 界面访问。

本版是 v26.10.1 之后的第二个正式发布版，继续提供 Windows x86_64 和 Linux x86_64 两种发行包。相比上版，主要改动是行版本并发控制、命名枚举类型和一批查询执行与安装体验上的改进。

## 本版新增

- 行版本与并发：默认快照隔离，SERIALIZABLE 写事务按表复查读依赖；死锁检测、锁超时和序列化失败返回结构化错误码；保存点回滚同步计划与读依赖；页写入前记录全页镜像，重启时修复可检测的撕裂页，逻辑恢复会重建受影响的派生索引。
- 在线整理：显式 compact 在独立文件代次复制堆与索引，追平并发修改后切换，结束后回收旧文件；旧快照未结束前保留其需要的文件。
- 命名枚举类型：支持 `CREATE TYPE ... AS ENUM`、列引用和 `DROP TYPE`；比较、排序、`MIN` / `MAX` 按标签声明顺序，不同枚举与文本列不能隐式混用；标签上限为 63 个 UTF-8 字节；CLI 与 Web 仍按文字标签显示和编辑。
- 查询执行：`LIMIT` 与 `ORDER BY` 相邻时改用分块排序加有界归并，只保留前 k 行；保序并行扫描、点查与范围查询的成本选择、哈希半连接 / 反连接、子查询物化和批量写入按查询形状与统计信息自动生效，不增加逐项开关。
- 安装与配置：安装器按平台选择 `settings.toml.linux` 或 `settings.toml.windows` 模板，替换数据目录和日志目录后写入；已有配置文件不会被改写。选择低性能适配（Linux `--low-performance-adapted`，Windows `-LowPerformanceAdapted`）时，把 `settings.low-performance.toml` 的参数覆盖进新配置，覆盖前保留备份。
- 身份与授权：本机 sudo 身份映射、速率限制、对象所有权与 grant option、权限变更后的会话失效沿用上版实现并补充了回归。

## 发行包与安装

每个平台一个压缩包，内含数据库服务端、初始化工具、命令行客户端、Web 界面和安装 / 卸载脚本，并附 SHA256 校验文件。安装时选择需要的组件：

```sh
curl -fsSL https://raw.githubusercontent.com/TheBadRoger/ChuSQL/main/scripts/install.sh | sh -s -- --component web
```

Windows 下载 zip 后运行包内的 install.ps1，可选择 Web 或 CLI 组件。下载失败时也可以用仓库中的安装脚本从源码构建。

安装与操作说明：[安装指南](https://github.com/TheBadRoger/ChuSQL/blob/v26.10.2/docs/install.md)、[SQL 语法](https://github.com/TheBadRoger/ChuSQL/blob/v26.10.2/docs/syntax.md)、[运行时类型](https://github.com/TheBadRoger/ChuSQL/blob/v26.10.2/docs/types.md)、[配置说明](https://github.com/TheBadRoger/ChuSQL/blob/v26.10.2/docs/config.md)。

## 兼容与限制

- 行版本快照使用格式 2 写入，读取兼容旧格式 1；新版写入后旧程序拒绝打开，回退前须恢复升级前的完整备份。
- 数据目录新增 `.pages` 和 `.page-wal`，停机备份与迁移必须复制整个数据目录，不能只复制 `.db` / `.idx`。
- 事务工作行集按整库物化，同库写入串行执行，适合学习、开发和小规模内部应用试点。
- `DECIMAL` 仍使用浮点表示；发行包只提供 SHA256 校验，没有发布签名。
- 本版已通过所有者全量门禁；发布流程要求 Linux 测试与两个平台的发行包安装验证全部成功后才上传正式下载包。

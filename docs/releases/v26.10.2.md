ChuSQL 是一个以 SQL 为主要接口的关系数据库，由 Haskell 查询引擎和 Rust 存储层组成。服务端管理数据与用户会话，命令行客户端和 Web 管理界面提供访问。

本版是 v26.10.1 之后的第二个正式发布版，继续提供 Windows x86_64 和 Linux x86_64 发行包。相比上版，主要改动是行版本并发控制、命名枚举类型，以及一批查询执行与安装体验上的改进。

## 本版新增

- 行版本与并发：默认快照隔离，SERIALIZABLE 写事务按表复查读依赖；死锁检测、锁超时和序列化失败返回结构化错误码；保存点回滚同步计划与读依赖；写入页面前记录全页镜像，重启时修复可检测的撕裂页，逻辑恢复会重建受影响的派生索引。
- 在线整理：显式 compact 在独立文件代次复制堆与索引，追平并发修改后切换并回收旧文件；旧快照需要的文件在快照结束前保留。
- 命名枚举类型：支持 `CREATE TYPE ... AS ENUM`、列引用和 `DROP TYPE`；比较、排序、`MIN` / `MAX` 按标签声明顺序，不同枚举与文本列分别处理；标签上限为 63 个 UTF-8 字节；CLI 与 Web 按文字标签显示和编辑。
- 查询执行：`LIMIT` 与 `ORDER BY` 相邻时改用分块排序加有界归并，只保留前 k 行；保序并行扫描、点查与范围查询的成本选择、哈希半连接和反连接、子查询物化、批量写入按查询形状与统计信息自动生效。
- 安装与配置：安装器按平台选择 `settings.toml.linux` 或 `settings.toml.windows` 模板，替换数据目录和日志目录后写入，已有配置文件保持不变。选择低性能适配（Linux `--low-performance-adapted`，Windows `-LowPerformanceAdapted`）时，安装器把 `settings.low-performance.toml` 的参数覆盖进新配置，覆盖前保留备份。
- 身份与授权：本机 sudo 身份映射、速率限制、对象所有权与 grant option、权限变更后的会话失效沿用上版实现并补充了回归。

## 发行包与安装

每个平台一个压缩包，内含数据库服务端、初始化工具、命令行客户端、Web 界面和安装、卸载脚本，并附 SHA256 校验文件。Linux 下载脚本后选择组件安装：

```sh
curl -fsSL https://raw.githubusercontent.com/TheBadRoger/ChuSQL/main/scripts/install.sh -o install.sh
sh install.sh --component web
```

Windows 下载 zip 后运行包内的 install.ps1，选择 Web 或 CLI 组件。

安装与操作说明：[安装指南](https://github.com/TheBadRoger/ChuSQL/blob/v26.10.2/docs/install.md)、[SQL 语法](https://github.com/TheBadRoger/ChuSQL/blob/v26.10.2/docs/syntax.md)、[类型与类型目录](https://github.com/TheBadRoger/ChuSQL/blob/v26.10.2/docs/types.md)、[配置说明](https://github.com/TheBadRoger/ChuSQL/blob/v26.10.2/docs/config.md)。

## 兼容与限制

- 行版本快照使用格式 2 写入，可以读取格式 1；回退到旧版程序前恢复升级前的完整备份。
- 数据目录包含 `.pages` 和 `.page-wal`，停机备份与迁移需复制整个数据目录。
- 事务工作行集按整库物化，同库写入串行执行，适合学习、开发和小规模内部应用试点。
- DECIMAL 使用浮点表示；发行包提供 SHA256 校验，发布签名待实现。

# ChuSQL 当前限制与风险

完成状态见 progress.txt，设计见 design-decisions.txt。以下是后续开发和部署需要关注的边界。

## 事务与恢复

- 延迟加载仍按表物化可见行，写入需要完整行；BEGIN 传输整库结构，COMMIT 比较修改表并检查最终行集。长期快照增加版本和文件保留成本。
- SERIALIZABLE 按表检查读依赖，可能因不同行变化产生保守冲突。每连接一个事务，DDL/USE 在事务结束后执行。
- 行锁和唯一键锁保留到事务结束，保存点回滚保留锁。死锁或 5 秒超时后须 ROLLBACK 并重做完整事务；未知提交结果先核对业务状态。
- 同库最终校验、WAL 发布和刷盘串行。原始存储 API 与 SQL 事务入口的校验和锁范围不同，完整 SQL 类型及约束检查由引擎负责。
- 库目录建删独立于表 WAL；恢复会重建受影响索引。recovery_required 时仅允许 Ping/SystemStatus 等明确例外。
- 页镜像处理可检测的撕裂写，任意介质损坏与真实断电保证仍需单独验证；离线 recover 依赖可用 WAL，缺失历史或损坏页可能需要完整备份。
- 格式 2 行版本和页侧文件要求完整目录备份，升级后回退须恢复升级前备份。旧进程可能没有目录锁，维护前停止所有相关进程。

## 容量与查询

- 整行编码须放入单页，默认 4096 字节且包含存储开销；尚无长行溢出。索引键默认上限 128 字节，旧配置可能为 64 字节，文本按 UTF-8 字节计算。
- 子查询物化缺少内存预算和磁盘溢出；成本估算使用有限统计，连接重排与半连接仅覆盖安全形状。
- CTE 仅支持非递归 SELECT；递归、写入型 CTE 及显式物化语法待实现。并行仅覆盖页区间扫描。
- compact 最终追平与切换独占库门，仍物化完整行集，切换时延随并发变化增长。

## 类型与接口

- DECIMAL 使用浮点，整数类型共用表示，CHAR 保留原字符串长度。运行时复合值索引、用户运算、精确十进制与用户复合类型待实现。
- DOMAIN 改名、基础类型变更、CASCADE、NOT VALID 和事务内类型 DDL 待实现；ALTER DOMAIN 仍读取整库快照。
- ENUM 支持命名定义，标签变更、列内 ENUM、通用 CAST 和跨枚举转换待实现；值携带标签集合，会增加行大小。
- 列与来源缺少独立身份，部分执行 API 仍允许名称引用。CHECK 以文本保存，列改名前须处理相关约束；原始存储调用不提供完整 SQL 语义保证。
- Web 复合值通过 SQL 编辑，JSON 数值受 JavaScript 安全整数范围限制；旧客户端不支持新增值编码。
- 范式分析最多 12 列，依赖用户声明，仅给一次分解建议，自动迁移待实现。

## 权限与客户端

- 列级权限、所有权转移、ADMIN OPTION、身份改名及更多角色属性待实现。大规模权限目录性能尚未量化。
- 旧授权、目录与非法字段名存在迁移边界，系统高水位损坏后无法还原已删除编号；升级前备份并核对现有配置。
- Web 同一会话仅一个页面持有编辑事务；断线后按超时清理，失效快照需重新登录。
- sudo 仅映射本机提升身份到显式配置账号。异常凭据目录须确认服务停止后清理；Windows 提升成功路径、macOS 及 Linux 完整提升链路仍待目标平台验收。
- CLI 旧历史由用户清理，外部采集可能保留 SQL。SHA256 仅检测损坏，发布签名待实现。

## 验收与应用边界

- 最近 deb 相关局部验证中，Web 83 例有 2 例因缺少 Node.js 失败；见 progress.txt。源码测试、驱动测试与镜像验收分别对应各自构建产物。
- 容器已验收 Linux amd64 和指定镜像；短期负载、SIGKILL、ENOSPC 与备份恢复不替代生产长期稳定性或任意版本升级验证。
- 当前优化尚未量化基准收益；GitHub 在线安装、Linux $ORIGIN 与 macOS 发布仍需目标环境验证。
- ChuBlog 生产迁移、HTTP/SSH 授权、哈希升级、限流及匿名身份合并由应用完成。缺少外键时，关联写入与删除使用 SERIALIZABLE 事务检查；受保护访问遇到身份或数据库错误应拒绝。
- 存储协议变化须重建实际动态库；Haskell 构建串行，必要时刷新 Stack 本地依赖。构建与测试入口见 AGENTS.md。

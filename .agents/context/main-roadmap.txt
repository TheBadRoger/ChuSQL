# ChuSQL 长期路线图

本文件描述方向，完成状态见 progress.txt，近期顺序见 side-branch-plan.txt。

目标链路：SQL → 解析与绑定 → 类型化计划 → 优化 → 执行 → Rust 存储。

| 阶段 | 方向 |
| --- | --- |
| 类型基础 | 稳定身份、注册表、逻辑/物理表示和版本化值 |
| 类型能力 | 运算符、转换、聚合、参数多态与约束解析 |
| 自定义类型 | 枚举、领域、记录、代数数据类型及参数化类型 |
| 函数与效果 | 用户函数、生成列和触发器 |
| 类型化查询 | 统一绑定、权限能力及查询重写 |
| 扩展机制 | 版本、依赖、安装、升级与移除 |

各阶段保持事务、权限与恢复约束，格式变化配套迁移或明确拒绝策略。兼容表示随消费者逐步迁移，用户数据依赖 WAL 与备份保护。

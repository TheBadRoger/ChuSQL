# ChuSQL 当前设计决策

只记录影响后续开发的选择与约束。完成状态见 progress.txt，待解决边界见 known-issues.txt。

## 组件与接口

- CLI 经 TCP 访问 Server，再由 Haskell 引擎通过 FFI 调 Rust 存储。Server 独占数据目录。
- Haskell 客户端从远程 ChuSQL-HaskellDriver 的 main 源码归档获取驱动。驱动自行定义协议数据，服务端使用 Server.Protocol 编码内核结果。配置、TOML、密码哈希、会话、限流、系统表与口令策略均位于服务端源码模块，CLI 和引导程序按需调用。
- 表存在性以 catalog 为准；语义检查和优化只使用 schema，索引由存储管理。
- 跨组件 JSON 使用稳定标签。FFI 响应由 Rust 分配、配套 free 归还；句柄关闭与请求串行，错误读取保持同一 OS 线程。
- 类型和值规则集中于 Core.Model/Core.Runtime，函数与绑定集中于 Engine.Runtime，错误分类集中于 Engine.Error；消费者迁移完成后再收拢兼容表示。
- 常用业务标量由 Core.Scalar 校验并生成规范文本，Core.Model 保留独立类型身份；沿用文本值编码及现有持久化顺序。引导向 __system_types 幂等登记 38 个类型名和别名，新增类型不改变已有编号。JSON、IP 与日历时长暂不开放顺序比较，时间限定已知偏移和微秒精度。

## 查询、类型与约束

- 查询和写计划绑定列位置，依赖覆盖对象身份、结构版本及传递类型定义。执行前和存储锁内复查，写守卫能力须明确确认，跨库按名称顺序取门。
- 优化保持结果、行序和错误时序。结构改写在绑定前完成；列查找遵守最近作用域，歧义明确报错。
- 写入统一检查类型、默认值、CHECK、非空和最终行集的唯一性。保留输入求值顺序、逐项赋值及未命中行不求值；失败不发布部分修改。
- DOMAIN 复用基础类型，继承约束；默认值按列、最近领域、基础领域选择。变更在一致快照上验证，发布时复查提交点，再走结构 WAL。
- ENUM 复用库内类型目录，类型身份与标签集合参与兼容性，排序和索引按声明顺序。复合类型按完整身份递归比较、排序和哈希，SQL NULL 与 Maybe Nothing 分开处理。
- DECIMAL 使用有限浮点和半值取偶舍入。复合值的查询能力与索引键能力分别验证。
- 计划缓存限最近一条只读查询，只保存结构与计划；权限逐次复核。子查询结果缓存限单次执行，Top-K 保持全排序前缀的稳定顺序。
- 优化由执行层按查询形状、统计和容量决定；配置用于资源预算，保持较少开关。

## 事务与持久化

- SQL 数据操作使用存储事务，按需加载开始快照的表与列。默认快照隔离；SERIALIZABLE 写事务按表复查读依赖，提交前检查合并后的最终约束。
- 行版本使用稳定且不复用的内部行编号；内容版本与位置变化分开。行锁和唯一键锁持有到事务结束，保存点回滚保留锁；等待在提交门外，死锁和 5 秒超时明确返回。
- 数据准备可并行，同库最终校验与发布串行；权限和 DDL 由全局公平门排序。版本变化也使原始管理员写入参与事务冲突检查。
- 发布顺序为逻辑 WAL、数据与索引、行版本、库检查点，再截断日志。提交组应用前进入 recovery_required，持久化任一步失败都保留恢复状态和日志。
- 行大小、索引键、id 冲突、名称及结构版本容量在 WAL 前校验；失败保留原文件。原始存储保留旧数据兼容行为，完整 SQL 语义由引擎负责。
- mvcc.json 格式 2 与带校验和的 mvcc.delta 保存版本，增量归并先发布快照再截断。完整记录损坏报错，撕裂尾部丢弃；旧格式 1 可读，回退使用升级前备份。
- 页覆盖前同步全页镜像，随后同步数据、发布页元数据并清理镜像。独立写序号区分同一提交中的重复页写；恢复按已提交组幂等重放并重建受影响索引。
- 显式 compact 用影子文件在线复制，最终追平后通过 WAL 切换文件代次。保持对象身份、结构版本和逻辑行序，旧快照结束后回收退役文件。
- 库建删使用目录与墓碑机制，独立于表级 WAL。停机备份包含整个目录及版本、页侧文件。

## 身份与安全

- 用户与角色共享名称空间和稳定编号；最高权限按身份属性判断，角色继承业务权限。保护最后一个启用且可登录的管理员。
- 授权绑定对象和身份编号；删除后不复用。撤销清理失去来源的下游授权，独立来源保留；事务提交复查权限和对象。
- 系统目录分层保护。受限目录管理者只管理普通身份。
- 初始化保留已有口令和属性。离线维护先在副本验证，保留备份再发布；repair 保持既有数据字节不变。
- CLI 按完整语句记录历史，含 IDENTIFIED/PASSWORD 的输入整体排除并对诊断脱敏；外部日志采集另行配置。

## 安装、发行与协作

- 配置由平台模板生成，已有配置保留；低性能适配覆盖前备份。Linux 用户安装走 XDG，系统安装走 /etc、/var 和服务账户。
- deb 使用 dpkg-deb 装配，首次随机口令保存于 /etc/chusql/admin-password（0600）。容器从 apt 安装固定版本的 deb，以 UID/GID 10001 运行，启动时幂等引导。
- GitHub Actions 负责构建测试，ChuRepo 提供发行和软件包渠道；发布脚本保持幂等。SHA256 校验损坏，签名与可信根仍属规划。
- 门禁先刷新实际 release 动态库，再并行运行 Rust、串行 Haskell 和注释检查；日志位于 logs/，构建统一 UTF-8。
- 博客业务用户由应用管理，权威业务状态与可重建索引分开。
- 文档按读者任务保留主要行为与关键限制；操作见 docs/，进度只在 progress.txt 维护。
